# Bugku CTF｜把猪困在猪圈里 Crypto WriteUp 题目信息 - 题目：把猪困在猪圈里 - 分类：Crypto 密码学 ## 一、审题分析 题目名字把猪困在猪圈里，直接提示密码类型：**猪圈密码 (Pigpen cipher，也叫共济会密码)**。 点击下载得到一段 Base64 字符串，不是直接密文，需要先解码还原图片。 > > 猪圈密码：用方框、角点符号代表 A‑Z26 个英文字母，属于图形替换密码。 二、解题步骤 步骤 1：Base64 解码得到图片 下载得到的内容是图片的 base64 编码字符串。 https://www.toolhelper.cn/EncodeDecode/Base 用此链接转化为图片 运行后得到图片文件，打开图片看到猪圈密码图形符号。 步骤 2：猪圈密码解密 猪圈密码有标准对照表，网上有在线解密工具。 在线工具参考：`http://www.hiencode.com/pigpen.html` 对照图片中的每一个符号查表，逐字符解密。 解密后得到明文：`thisispigpassword` 完整 flag： ``` flag{thisispigpassword} ``` ## 三、考点总结 1. **题目名字提示密码类型**：“猪” → 猪圈密码 Pigpen cipher； 2. Base64 还原图片，隐写 + 古典密码结合； 3. 掌握猪圈密码（共济会密码）的图形替换规则。 做题踩坑点 - ❌ 直接拿 base64 字符串去当作猪圈密码解密，完全无效； - ❌ 猪圈密码只处理大写 / 小写英文字母，没有数字符号； - ✅ 流程顺序：Base64 解码出图片 → 观察图片符号 → 对照猪圈密码表解密得到明文。 ## 四、拓展小知识 猪圈密码 (Pigpen Cipher)，18 世纪共济会使用的古典密码。 把 26 个字母分布在 3 组方框网格中，用方框轮廓、角标记来代表字母，只看图形形状就能完成加密解密。CTF 经常出现，看到 “猪” 关键词优先想到它。 **最终 flag：`flag{thisispigpassword}`**
