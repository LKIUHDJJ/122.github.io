Bugku Web 滑稽 Writeup

Bugku CTF《滑稽》Web Writeup

题目信息

平台：Bugku CTF

分类：Web

难度：签到题

分值：10 分

题目描述：打开页面满屏滑稽表情

题目分析

访问靶机链接，页面上铺满滑稽 emoji 图片，没有任何输入框、按钮，没有跳转。

考点：查看网页源代码（前端源码泄露），属于 CTF 最基础的签到题，flag 直接写在 HTML 注释里面。

解题步骤

打开题目网页，看到满屏幕滑稽表情。

两种方式查看源码：

  • 快捷键：F12 打开开发者工具，切换到Elements标签看 HTML；
  • 快捷键：Ctrl + U 直接查看页面源代码（推荐）。

在源码中往下翻，找到 HTML 注释 <!-- flag{xxxxxx} -->，复制大括号内内容。

把 flag 提交到 Bugku 平台，完成。

原理

网页上看到的只是前端渲染出来的图片，HTML 源码里可以写注释，浏览器不会展示注释内容，但查看源码时可以直接看到。服务器直接返回完整 HTML，没有后端校验，flag 明文写在页面注释中。

知识点总结

  • Ctrl+U / F12 查看网页源代码是 Web 题最基础操作；
  • HTML 注释 <!-- 内容 --> 不会在页面显示，但会随源码下发；
  • 前端源码泄露：敏感信息直接写在前端页面，不需要抓包、爆破、注入。

提示：Bugku 很多 Web 签到题都是查看源码，遇到页面只有图片、文字，优先 Ctrl+U。

踩坑记录

❌ 反复在页面上点来点去，页面肉眼看不到flag；

✅ 遇到纯图片页面，优先快捷键 Ctrl+U 查看源代码。
