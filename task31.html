Task31 第三十一个帖子 这是一张单纯的图片

Bugku CTF《这是一张单纯的图片》MISC 完整详细题解（全程不用写代码） 题目基础信息 题目名称：这是一张单纯的图片 题目类型：MISC 杂项（文件尾部附加 HTML 十进制实体编码） 题目描述：key{}，提供图片附件下载。 考点分析 下载得到一张 jpg 图片，图片肉眼看是正常普通图片。出题人在jpg 文件的文件末尾，直接追加了一串 HTML 十进制实体编码（格式&#数字;），图片本身的画面没有做任何隐写，没有修改图片宽高，没有 LSB 隐写。 HTML 十进制实体编码：&#数字;，数字代表字符的 ASCII 码，浏览器打开会自动把这串编码解析还原成正常可读字符。 很多新手直接看图，反复使用图片隐写工具（binwalk、zsteg）分析图片像素，什么都找不到，线索不在图片像素里，而是直接附加在整个图片文件的字节末尾。 步骤一：下载附件 点击下载按钮，拿到 jpg 图片文件。 不要双击看图，看图软件只会渲染图片画面，看不到文件末尾附加的文本编码。 方法 A：修改后缀为 html，浏览器自动解析（最简单，推荐） Windows 文件夹选项，勾选【文件扩展名】显示。复制一份图片副本，不要改动原始文件。 将副本文件后缀从.jpg重命名修改为.html。 双击这个 html 文件，用浏览器打开。浏览器会先尝试渲染图片，然后自动解析文件末尾的 HTML 实体编码。 使用快捷键Ctrl+F，页面内搜索关键词key，页面直接显示解析完成的key{...}。 复制完整结果提交平台。 方法 B：文本编辑器读取文件末尾，在线 HTML 实体解码 使用 Notepad++ 打开 jpg 图片，打开后大部分是乱码，滚动鼠标滚轮直接拉到文件最底部。 在文件末尾找到这一串编码： key{you are right} 完整复制这一整串编码，打开在线 HTML 实体解码网页。 将编码粘贴输入框，点击解码，直接输出明文 key。 方法 C：010 Editor / HxD 十六进制编辑器查看 把 jpg 图片拖入 010 Editor，滚动滚动条到文件尾部。 在右侧 ASCII 视图可以直接看见&#xxx;的实体编码字符串。 复制这一串字符，丢进在线 HTML 实体解码器得到 key。 高频踩坑点梳理 只看图画面：直接双击图片看图，画面上完全没有线索，线索藏在文件字节末尾，不是图片像素隐写。 使用 LSB 图片隐写工具扫描：zsteg、binwalk 扫描图片图片内容，得不到 flag，本题不是图片像素隐写，是文件尾部追加文本。 复制编码不全：只复制一部分末尾编码，解码得到乱码，要复制全部从k一直到最后的;}。 后缀修改错误：没有开启 “文件扩展名显示”，实际文件名变成1.jpg.html，表面看后缀还是 jpg，修改无效。 原理复盘总结 JPG 文件格式的解析规则：图片解析器读到 jpg 文件结束标记FF D9之后，后面多余的字节会被图片解码器直接忽略，所以看图软件看不到后面附加的文本。但是把整个文件当做 html 打开时，浏览器会读取全部字节，自动解析末尾的 HTML 实体编码。 做题记忆：MISC 遇到 “这是一张单纯的图片”，优先尝试文本编辑器拉到文件末尾看是否附加额外字符串，或者直接改后缀 html 用浏览器打开。 ✅ 本题 flag： key{you are right}
