Task21 第二十一个帖子 变量1

Bugku CTF《变量 1》WEB题目基础信息

题目名称：变量 1

题目类型：WEB

题目提示：无

题目描述：考察PHP可变变量$$、eval代码执行、$GLOBALS超全局数组、正则表达式过滤绕过

PHP可变变量语法：$$args，代表把$args里面字符串的值，当做变量名。

例如 $args = "abc"；$$args等价于$abc。

访问网页后，页面后端核心逻辑大致如下：

<?php

$args = $_GET['args'];

//正则校验，只允许字母、数字、下划线

if(!preg_match('/^\w+$/', $args)){

exit("error");

}

eval("var_dump(\$\$args);");

?>

通过 GET 方式接收参数args。

正则/^\w+$/做校验，\w代表大小写字母、数字、下划线，输入内容只能由这三类字符组成，其他符号直接报错退出。

把字符串放入 eval 执行，执行语句是var_dump($$args);。

flag 被隐藏在某一个不知名的全局变量中，我们不知道这个变量叫什么名字，不能直接访问。

解题思路原理：

PHP 中有一个特殊超全局数组叫做$GLOBALS。

$GLOBALS数组里面存储了当前 PHP 脚本全部的全局变量，所有定义过的全局变量，包括存放 flag 的那个未知变量，全部都会存放在$GLOBALS当中。GLOBALS这个字符串完全符合正则^\w+$的规则，全部是大写字母，没有特殊符号，可以顺利通过正则过滤。

当 GET 传入参数 args=GLOBALS：

$args变量的值就是字符串GLOBALS

$$args 就等价于 ${$args}，也就是$GLOBALS

eval 执行代码变成：var_dump($$args); → var_dump($GLOBALS);

var_dump 会把$GLOBALS里面全部全局变量完整打印输出到网页页面，存放 flag 的未知变量就会显示出来。

实操完整步骤（浏览器操作，不用写代码）：

打开题目给的靶场网页地址。

在浏览器地址栏 URL 末尾拼接 GET 参数：?args=GLOBALS

完整示例 URL：http://靶场地址/index.php?args=GLOBALS

⚠️重要踩坑提醒：部分浏览器会自动把地址栏大写字母自动转换成小写，变成?args=globals，这样就会失效。因为 PHP 里面$GLOBALS必须大写，小写 globals 不是这个超全局变量。如果遇到浏览器自动转小写，可以使用 Burp 抓包修改 GET 参数，或者复制完整链接粘贴，不要手动输入地址栏。

按下回车访问页面，页面会打印一大堆数组内容，也就是所有全局变量。

在一大段输出内容里面寻找那个名字随机的变量（本题存放 flag 的变量名为ZFkwe3），该变量的值就是 flag 的完整内容。

按照格式flag{xxx}复制提取 flag 提交即可。

常见踩坑点梳理：

大小写问题：传入args=globals小写，页面返回普通内容，拿不到 flag。GLOBALS必须全部大写，浏览器自动小写转换是高频踩坑点。

尝试传入其他变量名：我们并不知道存储 flag 的变量名称，直接猜变量名是行不通的，这道题的设计意图就是让你借助$GLOBALS一次性把全部全局变量打印出来。

尝试传入特殊符号：正则^\w+$不允许{ } $ & *等特殊符号，只要出现就直接 error，不能直接写$$、$GLOBALS放到参数里。参数只能填写纯单词字符串。

不要误解 eval 漏洞：这里 eval 并不是让你直接执行 system 命令，题目给 eval 的语句固定是var_dump($$args)，我们只能控制args字符串，不能篡改 eval 内其他代码。

题目考点复盘总结：

PHP 可变变量$$：把字符串解析成为变量名，是 PHP 经典 WEB 考点。

$GLOBALS超全局数组：保存脚本全部全局变量，当不知道目标变量名的时候，直接打印 GLOBALS 是常用技巧。

正则\w字符集理解：\w只匹配字母数字下划线，理解过滤允许哪些、禁止哪些字符。

浏览器对 URL 大写字母自动转小写的现实坑点，了解抓包修改参数的必要性。

eval 函数的风险，即使看起来限制严格的正则，结合可变变量依然会造成信息泄露漏洞。
