Task23 第二十三个帖子 Linux2

Bugku CTF《Linux2》MISC题目基础信息

题目名称：Linux2

题目类型：MISC 杂项

题目提示：给你点提示吧：key 的格式是KEY{}

题目描述：在Linux ELF二进制可执行文件中提取可读ASCII字符串获取flag

考点分析：

本题考察二进制文件中提取可读 ASCII 字符串。下载解压得到的附件是 Linux 平台下的二进制可执行文件，文件名叫做brave。直接双击或者用普通记事本打开，屏幕会输出大量乱码，因为文件主体是机器二进制指令，只有很小一部分是人类可读的文本字符，flag 就混杂在二进制乱码的可读片段里面。很多新手拿到二进制文件，直接 Windows 记事本打开，满眼乱码就直接放弃。本题不需要运行这个程序，不需要虚拟机，不需要 kali，Windows 工具就可以直接搜索关键词拿到 flag。核心思路：无视大量二进制乱码，直接在整个文件字节流里面搜索特征字符串KEY{。

步骤一：下载解压附件

在 Bugku 平台下载题目压缩包，解压，得到名为brave的文件，这个文件没有后缀名。

Windows 系统下看不到后缀，它本质是 Linux ELF 可执行程序，不要尝试双击运行，Windows 无法直接执行 Linux 程序，双击只会报错。

小科普：ELF 是 Linux 系统可执行文件格式，Windows exe 是 PE 格式，二者不兼容。文件内部除程序机器码以外，还会嵌入少量字符串文本，CTF 经常把 flag 直接藏在这些字符串中。

方法 A：Windows 十六进制编辑器 010 Editor / HxD（推荐，不装虚拟机）

直接把无后缀的brave文件，拖拽进 010 Editor 或者 HxD 十六进制编辑器。

编辑器会同时展示两部分内容：左侧十六进制字节，右侧是对应的 ASCII 文本区域，大部分位置都是乱码符号。

打开编辑器搜索功能，搜索关键词：KEY{（注意大写 K、大写 E、大写 Y，左大括号）。

⚠️搜索类型选择【ASCII 字符串】，不要搜十六进制数值。

搜索命中之后，光标直接跳转到 flag 所在位置，右侧 ASCII 窗口完整看到KEY{xxxxxxxxxxxxxxxxxxxxxxxx}，直接复制这一整串，就是本题答案。

复制完整KEY{...}，提交平台即可。

方法 B：Notepad++ 文本编辑器

将brave重命名，手动加上后缀.bin，变成brave.bin。

使用 Notepad++ 打开这个 bin 文件，屏幕大部分内容都是乱码。

使用 Ctrl+F 调出查找框，查找目标输入KEY{，查找模式选择 “普通”。

点击查找下一个，软件会跳过乱码定位到 flag 字符串，直接复制结果。

高频踩坑点梳理：

双击直接运行 brave：Windows 不能运行 Linux ELF 程序，双击只会弹窗报错，完全拿不到任何信息，本题不需要运行程序。

普通记事本打开乱码就放弃：Windows 自带记事本对二进制文件兼容性差，大量二进制字节会变成问号方块乱码，有可能直接截断，不推荐用系统记事本，优先使用 010、HxD、Notepad++。

搜索关键词大小写错误：必须搜索大写KEY{，小写key{搜索不到结果，题目提示格式是大写 KEY {}。

误以为需要 binwalk 分离文件：binwalk 扫描这个二进制，没有嵌套压缩包、没有隐藏图片，flag 直接存在文件字符串段，不需要分离提取其他子文件。

原理复盘总结：

MISC 二进制找字符串是非常高频基础题型：Linux ELF、Windows PE 程序，编译的时候，写在代码里面的字符串常量会原样保存在文件中。出题人直接把 flag 写进程序字符串常量，不需要执行程序，直接扫描文件字节就可以读取。

解题核心逻辑：不需要分析程序功能，不需要逆向代码，直接搜索 flag 特征模板 KEY {}。

✅ 本题完整 flag：KEY{24f3627a86fc740a7f36ee2c7a1c124a}
