Bugku CTF《贝斯家族》Crypto题目基础信息

题目名称：贝斯家族

题目类型：Crypto 密码学

题目提示：无

题目密文：@iH<,{bdR2H;i6*Tm,Wx2izpx2!

审题分析：

题目名字叫贝斯家族，“贝斯” 谐音 Base，提示这是 Base 系列编码，不是传统 base64、base32、base16。

密文：@iH<,{bdR2H;i6*Tm,Wx2izpx2!

观察字符，里面出现特殊符号：@ < , { * !

Base91 / Base92 是 Base 家族中字符集包含@、<、{等特殊符号的编码，优先测试 Base91。

什么是 Base91：

Base91 由 Joachim Henke 设计，是一种ASCII‑base 编码。

- 字符集比 Base64 更大，一共 91 个可打印 ASCII 字符；

- 可以输出@ < { , * !这类 base64 不会出现的符号；

- CTF 中见到@出现在密文，高度怀疑 Base91。

区分 Base91 与 Base92：两者字符集不一样，本题密文使用 Base91 解码可以直接得到 flag。

解题实操方式：

方式：Bugku 自带 Base91 在线工具

Bugku 平台内置 base91 工具：https://ctf.bugku.com/tool/base91

粘贴密文，选择解码，得到 flag。

考点总结：

1. 题目谐音提示：贝斯 = Base，定位 base 系列编码；

2. 字符集特征判断编码类型：出现@ { <，排除 base64/32/16，锁定 Base91；

3. 掌握不常见 Base 变体编码：Base91、Base92、Base85，是 CTF 密码学入门高频考点。

做题小技巧：

Base64：标志性特征字符 + / =

Base85：标志性特征字符 u

Base91：标志性特征字符 @ ! { < ,

Base92：更多控制类打印符号

踩坑提醒：

❌ 直接拿密文跑 base64 解码，会乱码，因为字符不在 base64 字符集；

❌ 直接当作 Hex，大量非法 hex 字符无法解析；

✅ 看到特殊符号 + Base 谐音提示，优先测试 Base91。

拓展：Base 系列编码区别

- Base16：十六进制，仅 0‑9 a‑f；

- Base32：大写 A‑Z，数字 2‑7；

- Base64：大小写字母、数字、+ / =；

- Base85：多用于 PDF；

- Base91：使用 91 个可打印 ASCII，字符集包含@ { < !，CTF 经常考。
