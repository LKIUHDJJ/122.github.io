Task5 第五个帖子 Bugku Web 头等舱

Bugku Web｜头等舱 Writeup

题目信息

平台：Bugku CTF

分类：Web

分值：15 分

考点：HTTP 响应头泄露 flag

页面现象：访问页面只显示 什么也没有。

Ctrl+U 看网页源代码，找不到 flag。题目名字 “头等舱” 暗示看头部（header）。

解法 1：浏览器 F12（不用 bp，新手优先）

打开靶机页面，按 F12 打开开发者工具

切换到「网络 (Network)」标签，刷新页面

点击第一条 GET 请求，切换到「响应头 (Response Headers)」

在响应头列表里直接找到 flag 字段，复制提交

⚠️注意：不是请求头，是响应头，服务器返回给浏览器的头部。

解法 2：Burp Suite 抓包

Burp 开启代理，浏览器访问页面，抓到 GET 请求

将报文发送到 Repeater，Send 发包

在 Response 的 Headers 区域，可以直接看到 flag，它不在 HTML 正文里，藏在 HTTP 头部行中

HTTP/1.1 200 OK
Server: nginx
Date: xxx
flag{xxxxxxxxx}      # flag在这里！
Content‑Type: text/html
……
<html>什么也没有。</html>

知识点总结：

HTTP 分为响应头 Headers和响应 Body 网页正文。

浏览器只渲染 Body 部分，响应头不会展示在页面上。Ctrl+U只能看 Body，看不到响应头。

提示词：题目名字带 “头”、header，优先检查网络响应头。

坑：很多人反复看页面源码，找不到 flag，就是忽略了 HTTP 头部。
