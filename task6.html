Task6 第六个帖子Bugku PWN 瑞士军刀

Bugku｜瑞士军刀 Writeup

题目信息

平台：Bugku CTF

类型：PWN（很多新手当成 Web）

分值：10 分

考点：nc (netcat)，网络界瑞士军刀

题目提示：nc ip 端口

netcat 简称 nc，被称为网络工具里的瑞士军刀，这就是题目的名字来源。

解题步骤：

打开题目，拿到靶机的 IP: 端口（页面直接给出）

打开 Kali（或者 Windows 安装 nc 工具），打开终端

使用 nc 命令连接靶机

nc 题目IP 题目端口

连接成功后，进入一个简易 shell 环境

输入ls列出当前目录文件，会看到有flag文件

ls

使用cat读取 flag 文件

cat flag

直接输出flag{xxxxxx}，复制提交即可

示例流程：

root@kali:~# nc 117.72.52.127 11511
ls
bin dev flag lib lib32 lib64 pwn1
cat flag
flag{9e861196d5a73bcd}

Windows 用户怎么操作（没有 Kali）：

下载 nc.exe（netcat）

cmd 中进入 nc.exe 所在目录

nc.exe 题目IP 端口

注意：Windows 自带 telnet 不行，必须 nc。

知识点总结：

nc（netcat）：TCP/UDP 连接工具，CTF 经常用来连接远程 shell；

Linux 基础命令：ls列出目录、cat读取文件；

这题不是网页题！不能用浏览器访问，浏览器是 http 协议，这里是原始 TCP 连接，必须 nc。
