题目名称：这不是 md5

题目类型：Crypto 密码学

题目提示：无

题目描述：666c61677b616537333538376261353662616566357d

审题：

坑点：很多同学第一眼会误以为这是 MD5 哈希值，直接拿去 md5 解密网站跑，肯定得不到结果，题目名字已经暗示我们，它不是 MD5

密文字符串：666c61677b616537333538376261353662616566357d

判断编码格式：

字符集合 0‑9 a‑f，这是典型十六进制（Hex，16 进制）编码特征。

十六进制编码规则：每两个十六进制字符代表 1 字节 ASCII 字符。

把串分组，每 2 个字符一组：66 6c 61 67 7b 61 65 37 33 35 38 37 62 61 35 36 62 61 65 66 35 7d

ASCII码对照解析：

66 → f，6c → l，61 → a，67 → g，7b → {，61 → a，65 → e，37 → 7，33 → 3，35 → 5，38 → 8，37 → 7，62 → b，61 → a，35 → 5，36 → 6，62 → b，61 → a，65 → e，66 → f，35 → 5，7d → }

拼接结果得到flag。

实操工具实现：

方法1：在线工具解码，找 Hex 转 ASCII 工具，输入字符串直接解码。

注意：编码选择ISO‑8859‑1 / UTF‑8，本题字符都是可见 ASCII，两种都可以。

踩坑记录：

❌ 错误操作1：复制字符串跑 MD5 解密，不可能出结果；

❌ 错误操作2：当成 Base64 解码，字符集中含有6c等，base64 会乱码；

✅ 正确思路：观察字符集 0‑f，结合题目名字，判断为十六进制编码，直接 Hex 转 ASCII。
